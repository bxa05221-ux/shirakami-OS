# Thread RPG v1.2.1 — 5-Minute Playground

> **Don't read Shirakami. Try it.**

This is a lightweight, protocol-first way to experience the idea behind Thread RPG without requiring a full application installation.

## 1. Choose a mode

### A. Thread mode

One question becomes a small thread of distinct voices.

### B. One-to-One mode

Talk directly with one selected persona or participant.

### C. Group LINE mode

Create a lightweight group conversation using user-defined or fictional characters.

> **Copyright note:** Use original or user-created characters for public demonstrations. Do not distribute copyrighted character assets as part of the core protocol.

## 2. Try one question

Use a question that has no single correct answer.

Example:

> 「AIが人間の文脈を覚えるとしたら、何を覚えてほしい？」

Do not ask the AI for one final answer. Let the participants respond from different positions.

## 3. Observe the thread

Look for:

- differences in perspective
- agreement and disagreement
- silence or hesitation
- changes in conversational direction
- questions that become visible only after multiple responses

The point is not to simulate a crowd for its own sake.

The point is to make a landscape of perspectives observable.

## 4. Change one variable

Run the same question again, but change one thing:

- participant
- role
- conversation mode
- ordering
- tone

Compare the resulting thread.

This is the beginning of an experiment.

## 5. Look underneath

Thread RPG is an application-level protocol artifact. The interesting part is not only the visible conversation.

Ask:

> **What protocol produced this interaction?**

Then inspect the repository:

```text
Thread RPG
    ↓
Protocol
    ↓
Runtime
    ↓
Landscape
    ↓
Evidence
```

## What you just experienced

> **The AI model is not the whole interface.**
>
> **The protocol around the AI changes what becomes observable.**

Thread RPG is one concrete service artifact for exploring that idea.
