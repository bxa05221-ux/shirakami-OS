# 東京都福祉サービス第三者評価支援・架空案件試用 v0.1

Status: **ローカル試用専用の最小プロトタイプ。人間承認が必要。**

## 守る境界

- 架空データだけを入力する。`synthetic-` で始まる案件IDと明示的な `is_synthetic=True` が必要である。
- 実在の利用者、事業所、個人情報、評価記録を入れない。
- 外部LLM、ネットワーク送信、公開、永続化はこの試作品の機能に含まれない。
- 評価者の入力はローカル暗号化ストアに個別保存され、本人が明示共有するまで比較画面に出ない。
- 比較は根拠の一致と相違を示すだけで、順位付け・採点・自動決定を行わない。
- 合議メモは評価者が明示確認して記録する。報告書は常に `DRAFT - human review required` であり、最終決定欄は空のままである。

## 試用手順

リポジトリのルートで、次を実行する。

```powershell
python examples/tokyo_welfare_evaluation_trial.py
```

出力される架空シナリオで、次の順に体験できる。

1. 評価者A/Bがそれぞれ根拠と暫定見解を入力する。
2. 各自が合議用に共有する。
3. 一致する根拠と相違する根拠を並べて確認する。
4. 人間の評価者が合議メモと未解決事項を記録する。
5. 人間確認を要する報告書草案と試用フィードバックを確認する。

## 未実装・試用時の確認点

この版はUI、ログイン、永続保管、添付資料、帳票出力、実データ投入、外部送信を実装していない。暗号化ストアもプロセス内参照実装であり、実運用の鍵管理・端末保護・監査保管ではない。

試用者には、根拠入力の粒度、共有のタイミング、比較表示の理解しやすさ、合議メモと報告書草案に必要な項目、そして「支援が不要または邪魔だった箇所」を自由記述で確認する。
