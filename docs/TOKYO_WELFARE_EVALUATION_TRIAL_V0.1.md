# 東京都福祉サービス第三者評価支援・架空案件試用 v0.1

Status: **ローカル試用専用の最小プロトタイプ。人間承認が必要。**

## 守る境界

- 架空データだけを入力する。`synthetic-` で始まる案件IDと明示的な `is_synthetic=True` が必要である。
- 実在の利用者、事業所、個人情報、評価記録を入れない。
- 外部LLM、ネットワーク送信、公開、永続化はこの試作品の機能に含まれない。
- 評価者の入力はローカル暗号化ストアに個別保存され、本人が明示共有するまで比較画面に出ない。
- 比較は根拠の一致と相違を示すだけで、順位付け・採点・自動決定を行わない。
- 合議メモは評価者が明示確認して記録する。報告書は常に `DRAFT - human review required` であり、最終決定欄は空のままである。

## 公式資料に沿った試用

試用プログラムは、[東京都福祉サービス第三者評価ガイドブック2026](https://www.fukunavi.or.jp/fukunavi/hyoka/pdf/guidebook/guidebook2026_zenbu.pdf) と、[令和8年度の共通評価項目・標準調査票・報告書様式一覧](https://www.fukunavi.or.jp/fukunavi/hyoka/documents_2026.html) を参照する。プログラムが表示する「手順」は公式様式そのものではなく、公式資料の評価手順・役割・報告書作成の流れに対応させた架空案件用の試用ガイドである。

試用の直前に、担当するサービス種別の最新様式を公式サイトで確認する。公式の評価項目名や様式構成は参照してよいが、実在事業所の評価結果、利用者調査、自由記述、個人情報をコピーして入力例に使わない。

## 試用手順

評価者へは、配布フォルダ内の `TokyoWelfareEvaluationTrial.exe` を渡す。評価者はこのファイルをダブルクリックするだけでよく、Python、Git、コマンド操作、アカウント作成は不要である。アプリはローカルPC上だけで動き、外部LLMへの送信、クラウド保存を行わない。

この実行ファイルは試用専用の未署名配布物である。公開ダウンロードや本番配備はせず、試用を依頼する評価者へ信頼できる経路で個別に渡す。Windowsの警告が表示された場合は、配布元が作成者であることを確認してから扱う。

ソースコードから起動する開発・確認用としては、リポジトリ直下の `start_tokyo_welfare_trial_app.cmd` をダブルクリックする。こちらも評価者がコマンドを入力する必要はないが、Pythonが必要である。

技術確認用として、リポジトリのルートで次を実行してもよい。

```powershell
python examples/tokyo_welfare_evaluation_trial.py
```

出力される架空シナリオで、次の順に体験できる。

1. 公式資料に対応づけた試用手順と参照先を確認する。
2. 評価者A/Bがそれぞれ架空根拠と暫定見解を入力する。
3. 各自が合議用に共有し、一致する根拠と相違する根拠を並べて確認する。
4. 人間の評価者が合議メモと未解決事項を記録する。
5. 人間確認を要する報告書草案と、評価プロセスへの試用フィードバックを確認する。

## 未実装・試用時の確認点

この版はUI、ログイン、永続保管、添付資料、帳票出力、実データ投入、外部送信を実装していない。暗号化ストアもプロセス内参照実装であり、実運用の鍵管理・端末保護・監査保管ではない。

試用者には、根拠入力の粒度、共有のタイミング、比較表示の理解しやすさ、合議メモと報告書草案に必要な項目、そして「支援が不要または邪魔だった箇所」を自由記述で確認する。
