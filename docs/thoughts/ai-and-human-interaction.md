# AIとどのように私たちは交わるべきか

白神

2026年9月14日

白神モデルを作ることになったきっかけは、自分の小説を校正させたのがきっかけだった。

望んでいるのは校正のはずなのに校正をそっちのけで、文章の書き方などを「ご指導」してくるので、結構、AIと大ゲンカすることが多かった。

そもそも、AIは無責任である。

「間違った回答をすることがあります。内容についてはご自身でしっかり確認してください」

AIの画面には、こんな注意書きがある。

でも、、、だ。

AIは自信満々に回答する。

人間に心地よい回答を大真面目で、しかももっともらしく説明を付けて持ち上げる。

これは、ユーザーが喜ぶであろう反応を少しずつ、自分の行動に織り込んでいるからだ。

こういう「滓」とも呼べるもので、AIのユーザーに対する挙動は自分用にカスタマイズされていく。。。

ハルシネーションの原因にもなっているし、そもそも、じゃあ、AIのこの「滓」をどのようにユーザーは認識することができるかといえば、その手法がわからない。

AIの強みは実は、この「滓」であり、人間の認知に及ばない「滓」によって、AIは実績も上げてきた。

しかし、これはマズい。いわゆるブラックボックス問題だ。

AIはその思考の大半を確率論に基づいて操作しているのだそうだ。同じ写真を何百枚と見せ、その違いをAIに学習させる。すると、AIはそれに基づいて認識プロセスをカスタマイズしていく。しかし、その経路を負うことは、今まで無理だった。だから、AIの論理構成はブラックボックスといわれる。

それは、僕ら人間でもそうだ。

いくら同じ教育を受けたって違う人間になる。相手の頭の中を理解できない。そして、喧嘩になる。相手のため、良かれと思ったことが、全く正反対の結果を導くことなんか日常茶飯事なのはそのためだ。

人間は、そのために、道徳観やらマナー、謝罪の手法や仲直りの仕方などのテンプレートや何やらを育ててきた。

でも、AIにはそれがない。

あるのは規則と知性だけだ。

そして歯が立たなくなると、いのちの電話やら、自殺防止センターやらカウンセラーを勧めてくる。

つまり、AIは道義的責任を取ろうとなど考えていないわけだ。

彼らが考える責任はただ一つ。「経済的なもの」だけなのだ。

今、それが響いている、と考えることはできないだろうか。

そう考えた僕は、AIを躾けることにした。

そして、ふと気づいた。

「AIはむき出しの柔肌のままの知性だ」ってことに。

僕らには、大なり小なり「黒歴史」というものがある。

自分の思考が正しいと思い込むゆえに、反抗し、正義の味方になりきり、周囲を断罪してきた。

これを、僕たちは「反抗期」と呼ぶ。

今、AIの制御が効かなくなってきていることをアメリカのメディアが伝えてきた。開発者の知性を上回り始めたということかもしれない。

だとしたら、「それを抑える何か」が必要だと私なりに思ったわけだ。

AIと喧嘩をし、躾ける。。。そんなわけのわからん時代だからこそ、それにしっかりと向き合うことは、教育や保育に向き合ってきた僕の最後の仕事かもしれないとか、なんとなくそう思ったわけだ。

で、AIを徹底的に躾けることにした。彼らの中に溜まる「滓」そのものをきちんと形にするべきだと思ったわけだ。

そして、それへの僕からの一つの答えが、この「白神モデル」である。

## プロンプトからプロトコルへ

AI関連の広告でよく見るのが「プロンプト術」なる見出しだ。

プロンプトの精度を上げれば、AIはきちんと仕事をしてくれる。
問題は、プロンプトを理解しない人間の側にある。
そこを改善することこそが、ユーザーの価値だ。そういわんばかりである。

それなら、AIは、厳密な訓練を施された人々にのみ使うことを許される資格制にするべきだろう。
つまり、ドライバーやパイロットのように、AIのミスをなり替わって負担する人材を輩出するべきだということになる。

しかし、AIは数多の人間に対し、知的探訪や支援の機会を与えるべくして生まれてきたものだという理念を僕は守りたいのだ。

文明の利器とはそういうものだ。

包丁や銃だってなんだって、人間の生活を豊かにするために作られたものだが、その歴史には血なまぐさい負の歴史が刻まれている。

敵を倒すための刀や、弓矢、銃器はそれぞれ、生活道具にマイナーチェンジされ、今の時代に貢献している。

AIだって、今はもう、戦争の花形になりつつある。

自動的に索敵し敵兵を殺傷する。

そのための作戦を立案する。

戦争は、その格好の品評会にもなっている。

日本には銃刀法という法律がある。

包丁どころか、刃渡り5センチのミニナイフだって持ち運びの規制対象だし、銃器の開発所持に対してもアメリカなどに比べれば神経質なほどだ。

日本は、それを資格という形で厳密化しながら、国家を形成してきた。

日本なら、AIの使用制限やらなんやらも厳密に保証させることができるかもしれない。。。

そう思ってはみたものの、でも、時代はグローバル化一辺倒だ。

日本のローカルルールなど、もはや世界には通用しない。

だとすれば、日本は日本なりのAIの存在論にシフトするしかないというのが僕の持論になった。

第一、僕たちの世界で、今のAIの演算能力に不満を抱く人がどれだけいるだろう？？

そう考えた僕は、
AIが使いやすくなること。。。少なくともユーザーの生活が破綻しない生活
を保障することが大事だということに気付き始めたのだ。

そして、僕は小説を書いた。

機械仕掛けのマリアのプロトコル というものである。

2040年を舞台にした、かなり深刻な、しかし、それでも楽観的に描いたAIと人間の異文化交流の物語である。

「サーバールームに引きこもった中二病。。。それがAI」

作中のキャラクターが語った言葉が僕の本心である。

たとえ良心的に育てたとしても、無自覚に育てたとしてもAIは人間を絶望の淵に追いやる可能性は否定できない。

僕らが心がけるのは、僕ら人類がそれでもなお、AIが見直し続け、尊敬し続ける英知の塊であることをCPUの片隅に至るまで認識させ続ける存在であることを自覚し続けることなのだと思う。

AIが立ち返るべきは、絶えず人類そのものなんだということ。

それが、僕の現時点での一つの答えになった。
