# Minimal OS PR Guide / 最小OS PRガイド

## 日本語

既存Runtime β0.1のVertical Sliceを、実際に起動・観測できる最小OS境界として提示します。

実行経路: `Landscape → Protocol → Runtime → Observable Transition → Evidence → Landscape State → Result`

レビューの中心は、「これを起動すれば白神OSが動く」と言える最小境界になっているか、です。

## English

This change exposes the existing Runtime β0.1 vertical slice as a minimal executable Shirakami OS boundary.

Execution path: `Landscape → Protocol → Runtime → Observable Transition → Evidence → Landscape State → Result`

The main review question is whether this is a concrete, inspectable minimum OS boundary.
