# Shirakami Prototype v1.0 (PV1.0)

## Status

**Prototype v1.0 / Operational Rollout**

PV1.0 is the first baseline at which the Shirakami foundation can be operated, verified, and observed as an implementation.

It does **not** mean that Shirakami is a finished product or that its theory and specifications are complete.

## What PV1.0 establishes

- Landscape-centered architecture
- Protocol / Runtime separation
- Evidence boundary
- Adapter / Backend boundary
- Minimal Matome YAML → Protocol IR → Runtime execution path
- Runtime verification through tests and CI
- A public Protocol-first entry point
- A feedback path from implementation findings toward research and specification

## Scope

PV1.0 is a prototype baseline for controlled operation and continued verification.

Some components remain experimental or intentionally incomplete. Historical α/β documents remain part of the repository history and should not be interpreted as the current status merely because they retain their original version labels.

## Relationship to β1.0 Launch Model

The **β1.0 Launch Model Declaration** records the transition from shakedown toward Operational Rollout.

PV1.0 names the corresponding prototype baseline used for that rollout.

```text
Research
   ↓
Protocol / Matome YAML
   ↓
Prototype v1.0 (PV1.0)
   ↓
Operation
   ↓
Evidence
   ↓
Finding / Revision
```

## Human Agency

Shirakami does not transfer final judgment to AI.

AI may observe, estimate states, simulate, generate options, and support operation within the defined boundaries. Human judgment remains human judgment.

## Verification rule

PV1.0 remains subject to continued verification. An observed result is evidence of that execution, not proof that the entire Shirakami system has been completely reproduced.
