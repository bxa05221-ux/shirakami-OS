# 白神の仕組み

白神は、AIそのものを作り替えるのではなく、AIと人間の間に文脈・記録・ルールを置く構造です。

```text
Landscape → Evidence → Protocol → Runtime → Adapter → 外部AI / Backend
```

## Landscape

人間や現場が持っている文脈です。

## Evidence

実際に起きたことの記録です。

後から都合よく意味を書き換えるためのものではありません。

## Protocol

白神がどのように扱うかを定めたルールです。

## Runtime

Protocolを実行し、状態を扱い、観測結果を記録する実行部分です。

Runtime自身を「正解を決める存在」にはしません。

## Adapter

白神と外部のAIやシステムをつなぐ交換可能な境界です。

そのため、特定のAIベンダーだけに白神の意味を固定しないことを目指します。

## Renderer

人間が結果を見るための表示部分です。

表示そのものを意味の最終的な根拠にはしません。

## 重要な境界

- AIに最終決定権を渡さない
- Realityを勝手に変更しない
- EvidenceをRendererから再構成しない
- Adapterを交換可能にする
- 不明なものを、分かったことにしない
