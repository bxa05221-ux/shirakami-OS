# Shirakami OS RFC

## Purpose

This directory contains Request for Comments (RFC) documents for Shirakami OS.

RFCs describe architectural proposals, design discussions, and implementation guidelines before they become part of the Foundation.

---

## Principles

- Foundation is immutable.
- RFCs are discussion documents.
- Architecture precedes implementation.
- Repository structure is part of the architecture.

---

## Lifecycle

Proposal

↓

Review

↓

Revision

↓

Accepted

↓

Foundation

---

## Scope

RFC documents may define:

- Repository conventions
- Runtime architecture
- Plugin architecture
- Adapter contracts
- Renderer architecture
- Public APIs

Implementation details belong to later development phases.

---

## Current RFCs

- RFC-0001 Plugin Classification
- RFC-0002 Plugin Lifecycle
- RFC-0003 Runtime Lifecycle
- RFC-0004 Plugin Contract
- RFC-0005 Contract Layer Overview
- RFC-0006 Runtime Interface Contract

RFC-0006 is currently marked Draft.

---

## Foundation Relationship

RFCs are architectural discussion and proposal documents. They do not automatically become Foundation merely by existing in this directory.

The current Foundation Base Point is documented separately under `spec/` and the repository root documentation.

---

Shirakami OS follows a Foundation-first development model.

Architecture is established before implementation.
