# RFC Transition Index

The RFC documents in this directory record architectural decisions and contract proposals developed during Shirakami OS design.

Some RFCs have since been promoted into the normative `shirakami-specification` repository. The original files remain here temporarily to preserve repository history and transition context.

## Promoted

- RFC-0001 → `shirakami-specification/architecture/PLUGIN_CLASSIFICATION.md`
- RFC-0002 → `shirakami-specification/contracts/PLUGIN_LIFECYCLE.md`
- RFC-0003 → `shirakami-specification/contracts/RUNTIME_LIFECYCLE.md`
- RFC-0004 → `shirakami-specification/contracts/PLUGIN_CONTRACT.md`
- RFC-0005 → `shirakami-specification/architecture/CONTRACT_LAYER_OVERVIEW.md`

## Draft / Active Design

- RFC-0006 — Runtime Interface Contract

RFC-0006 remains a draft and is intentionally not treated as a normative specification.

## Transition Rule

New normative references should point to `shirakami-specification`. This directory is now primarily an RFC history and active-design area.
