# Shirakami OS 格言集

> ノベルティ・展示・紹介資料などへの転用候補。
> 現時点では理念・開発文化の記録であり、技術仕様ではない。

## Core Maxims

### 1. 事実は先、理論は後からついてくる。

まず実際に起きたことを観測し、記録する。
理論付けや解説は、その後でいい。

### 2. 理論付けや解説は、頭のいいやつに任せる。

現場で起きたことを、先に理論へ押し込めない。
専門家による説明は、観測された事実の後ろに置く。

### 3. 飛びたいなら、飛ぶ方法を見つければいい。

自分がエンジンの専門家である必要はない。
必要なものを組み合わせ、まず飛ばしてみる。

### 4. AIは人間の代わりに生きるものではない。

AIは人間だけでは見えなかった景色を見せる。
最終的に選ぶのは人間。責任も人間に残る。

### 5. 記録できることと、記録してよいことは同じではない。

Landscapeを扱うほど、本人主権が重要になる。

### 6. EvidenceとInterpretationを混同しない。

何が起きたかと、それをどう解釈したかは別のものとして扱う。

### 7. 描くとは、暴くことではない。

相手の防衛層を破壊するのではなく、その人がそこに至った理由を抱えたまま、もう一度歩かせる。

### 8. 巡礼とは、誰かの仮面を剥ぐことではない。

仮面をつけた理由を抱きしめたまま、その人をもう一度歩かせる。

### 9. 人間の代わりに走らない。人間が走れる景色をつくる。

ガイドランナーとしてのAI。
