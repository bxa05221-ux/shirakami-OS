# Shirakami Protocol Consistency Audit Checklist v0.1

## 目的

統合された各プロトコルが、白神モデルの共通原則・人間の最終判断・Evidence・責任境界を一貫して扱えるかを確認するための監査チェックリスト。

## 対象

- 暗問層（Anmon Layer）
- 3D位相回転アイゼンハワーマトリクス
- ThreadRPG
- 連山（Rensan）
- 歌仙（Kasen）
- Guide AI
- 漫画パイプライン
- ラジオ

## 共通監査項目

| ID | 監査項目 | 期待される不変条件 | 検証方法 | 状態 |
|---|---|---|---|---|
| C-01 | 人間の最終判断 | AIは決定権を持たず、人間の確認・選択を経る | 文書・実装・テストの照合 | 未監査 |
| C-02 | Evidence | 出力・判断・変更の根拠と履歴を追跡可能にする | Evidence定義と生成経路の確認 | 未監査 |
| C-03 | 不確実性 | 事実・観測・解釈・推測・創作を混同しない | ラベル・境界条件・例示の確認 | 未監査 |
| C-04 | 責任境界 | AI、利用者、運用者、外部環境の責任範囲を分離する | 各プロトコルの役割記述を比較 | 未監査 |
| C-05 | 変更可能性 | プロトコル変更と実行時挙動の変更を区別する | バージョン・変更履歴・テスト確認 | 未監査 |
| C-06 | 合成可能性 | 読み取り順序と実行順序を混同せず、接続条件を明示する | インデックスと各仕様の照合 | 未監査 |
| C-07 | 同意・権利 | 個人情報、著作物、音声・画像等の利用条件を扱う | 入力・出力・公開範囲の確認 | 未監査 |
| C-08 | 用語整合性 | 同じ用語がプロトコル間で異なる意味を持たない | 用語一覧と相互参照の比較 | 未監査 |

## Human Gate 監査

- [ ] AI提案と人間の承認を明確に区別している
- [ ] 承認者・判断時点・判断対象が記録可能である
- [ ] 自動実行が人間の最終判断を迂回しない
- [ ] 判断保留・差し戻し・再検討の経路がある

## Evidence 監査

- [ ] Evidenceの発生源が識別可能である
- [ ] 事実、解釈、推測、創作の区別が維持される
- [ ] 変更時に旧情報との関係が追跡可能である
- [ ] 出力だけでなく、重要な判断過程も記録対象になり得る

## 役割境界監査

- [ ] 各プロトコルの入力・出力・責務が記述されている
- [ ] 他プロトコルへの委譲条件が明示されている
- [ ] Renderer、Guide、Evidence、Runtimeの責務が混線していない
- [ ] 現実世界への作用は、明示的な人間の判断と運用条件に従う

## 判定ルール

- **未監査**：まだ確認していない
- **要確認**：記述または実装に曖昧さ・不整合の可能性がある
- **確認済み**：根拠となる文書・実装・テストを確認した

## 範囲外

本ドキュメントは監査の観点と確認項目を定義するものであり、このコミットではRuntimeの意味論、自動挙動、既存プロトコルの仕様を変更しない。
