# One-Stroke Route Pipeline Alpha 0.1\n\n## Purpose\nConnect a structural n-gram Route Candidate to one human-gated Runtime execution, verification, and Evidence capture.\n\n## Boundary\nCandidate -> Human Gate -> One-Stroke Runtime -> Verify -> Evidence\n\nThe candidate is structural only. Semantic compatibility is not inferred.\n\n## Rules\n- Candidate contains at least two distinct Protocol identifiers.\n- A human reviewer must explicitly approve the selected candidate.\n- Only the selected Protocol implementations are composed.\n- The composed route executes as one Runtime operation.\n- Verification checks the expected route transition kind.\n- Runtime Evidence is retained after execution.\n- Missing implementations fail closed.\n- No step grants authorization or changes reality by itself.\n\n## Non-goals\nThis alpha does not infer semantic compatibility, select a candidate on behalf of a human, or claim that a verified execution proves the route is universally correct.\n
