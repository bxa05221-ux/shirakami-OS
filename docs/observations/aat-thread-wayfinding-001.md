# AATS Thread Wayfinding 001

## Purpose

Connect the AATS-origin Thread experience to one complete observable user-facing turn:

`AATS → Renzan → Kasen → Landscape observation → external Small Step → re-observation`

## Boundary

- AATS supplies transient Thread / Participant / Post state.
- Renzan preserves posts as observable viewpoints.
- Kasen re-expresses viewpoints for the human-facing surface.
- Landscape observation is supplied through an external observer boundary.
- Small Step selection is supplied through an external policy boundary.
- Step application is supplied through an external execution boundary.
- The resulting Landscape is observed again.

## Non-goals

- No cognitive echo-location implementation in the Kernel.
- No 3D-PRUIM semantics in the Kernel.
- No truth inference or hidden-state inference.
- No fixed participant roles.
- No participant persona/IP editor.

## Lineage

`AATS → Thread RPG → later applications such as 旅とも`

## Operational meaning

This makes the existing components usable as one continuous service path rather than isolated capabilities. External intelligence may be replaced without changing the runtime boundary.
